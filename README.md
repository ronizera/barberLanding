# Barbearia Landing Page 💈

Landing page desenvolvida para uma barbearia moderna, com foco em identidade visual, apresentação de serviços e atração de novos clientes.

## 🎯 Objetivo
Apresentar uma barbearia de forma profissional, destacando serviços, estilo visual e facilitando o contato com clientes.

## ✨ Funcionalidades
- Seção institucional
- Apresentação de serviços
- Layout responsivo
- Design moderno e minimalista
- Estrutura pensada para conversão

## 🛠️ Tecnologias Utilizadas
- React
- Next.js
- Tailwind CSS
- JavaScript



## 📌 Aprendizados
- Criação de interfaces institucionais
- Aplicação de conceitos de UI/UX
- Responsividade e mobile-first
- Componentização no React

## 📄 Observação
Projeto desenvolvido para fins de estudo e portfólio.
